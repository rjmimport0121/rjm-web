# rjm-web
Web oficial RJM Import-Export E.I.R.L. — https://www.rjmimport.com/

Sitio estático (sin compilación):

- `index.html`: página pública. Los productos con precio se cargan desde Supabase.
- `admin.html`: panel del administrador (productos, lista mayorista y usuarios).
- `mayoristas.html`: portal privado para clientes mayoristas.
- `supabase/`: esquema de base de datos y función de servidor.

Configuración paso a paso: [docs/CONFIGURACION.md](docs/CONFIGURACION.md)
